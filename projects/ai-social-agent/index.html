AI Social Media Agent

Automatización inteligente para generar y publicar contenido diario en X (Twitter) usando RSS + Make + GPT, integrada con el ecosistema MMDV.

Resumen del proyecto

Este proyecto desarrolla un agente social autónomo capaz de:

  • Leer noticias en tiempo real desde fuentes RSS especializadas en vino.
  • Seleccionar automáticamente una noticia mediante un sistema aleatorio controlado.
  • Generar un tweet con mi estilo (“Mi Mundo del Vino”).
  • Crear una imagen coherente con el contexto de la noticia.
  • Publicar automáticamente en X usando un bot propio desplegado en Render.
  • Registrar cada post en una base de datos de Notion para análisis posterior.

La integración está construida con Make (antes Integromat), OpenAI GPT-5.1 para texto, DALL-E 3.5 para imágenes y un backend propio en Python/FastAPI para controlar la publicación en X mediante OAuth1.

Arquitectura del agente

A nivel funcional, el flujo completo del agente es:

  • RSS Watcher: escucha nuevas noticias (Wein.plus, Decanter, OIV…).
  • Selector aleatorio: módulo Switch que rota entre 3 feeds.
  • GPT – Redacción: genera el texto del tweet con mi estilo.
  • DALL·E – Imagen: crea una imagen contextual y coherente.
  • HTTP → Bot X: envía texto + imagen al backend propio.
  • Notion: registra datos del post, URLs, métricas iniciales…

Bot de publicación en X

La pieza clave del sistema es un bot propio desplegado en Render que recibe peticiones desde Make y publica en X mediante OAuth1.

El bot expone un endpoint /tweet-with-image que recibe:

  • text: tweet final generado por GPT y sanitizado.
  • image_base64: imagen creada por DALL·E 3.5.

El backend valida el payload, gestiona errores de la API de X y devuelve el ID del tweet para que Make lo registre en Notion.

Problemas técnicos superados

1. Límite de 4000 caracteres en prompts

Solucionado dividiendo prompt fijo + contenido dinámico limpio.

2. Fusión de múltiples RSS

Make no permite fusionar varios Watch; se resolvió con Switch + un único Retrieve feed.

3. Penalización de X por imágenes inestables

Se añadió verificación previa + fallback automático.

4. JSON roto por comillas

Sanitizador automático que limpia el texto sin romper emojis.

Resultado final

El agente publica de forma autónoma una noticia diaria de vino con: texto personalizado + imagen generada + registro automático en Notion.
