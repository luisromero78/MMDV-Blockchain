AI Social Media Agent

Automatización inteligente para generar y publicar contenido diario en X (Twitter) usando RSS + Make + GPT, integrada con el ecosistema MMDV.

Resumen del proyecto

Este proyecto desarrolla un agente social autónomo capaz de:

  • Leer noticias en tiempo real desde fuentes RSS especializadas en vino.
  • Seleccionar automáticamente una noticia mediante un sistema aleatorio controlado.
  • Generar un tweet con mi estilo (“Mi Mundo del Vino”).
  • Crear una imagen coherente con el contexto de la noticia.
  • Publicar automáticamente en X usando un bot propio desplegado en Render.
  • Registrar cada post en una base de datos de Notion para análisis posterior.

La integración está construida con Make (antes Integromat), OpenAI GPT-5.1 para texto, DALL-E 3.5 para imágenes y un servicio backend propio en Python/FastAPI para controlar la publicación en X mediante OAuth1.

Arquitectura del agente

A nivel funcional, el flujo completo del agente es:

  • RSS Watcher: escucha nuevas noticias (Wein.plus, Decanter y otras fuentes europeas).
  • Selector aleatorio: módulo Switch que elige 1 de las 3 feeds cada día.
  • GPT – Redacción: genera el texto del tweet con mi tono y estilo.
  • DALL·E – Imagen: crea una imagen coherente con el tema de la noticia.
  • HTTP → Bot X: envía texto + imagen al backend propio.
  • Notion: guarda URL, prompt, ID de tweet, métricas iniciales…

Bot de publicación en X

La pieza clave del sistema es un bot propio desplegado en Render que recibe las peticiones desde Make y publica en X con autenticación OAuth1.

El bot expone un endpoint /tweet-with-image que recibe:

  • text: tweet final ya formateado y sanitizado (sin romper emojis).
  • image_base64: imagen generada por DALL·E, codificada en base64.

El backend valida el payload, gestiona errores de la API de X (incluidas penalizaciones por imágenes inestables) y devuelve al escenario de Make el ID del tweet para registrarlo en Notion.

Problemas técnicos superados

1. Límite de 4000 caracteres en prompts

Se solucionó dividiendo el prompt en instrucciones fijas + contenido dinámico limpio, resumiendo la noticia antes de inyectarla en el prompt de imagen.

2. Fusión de múltiples RSS

Make no permite usar varios módulos Watch RSS como un único trigger, así que se usó un Switch aleatorio más un solo módulo Retrieve RSS feed items mapeado dinámicamente.

3. Penalización de X al enviar imágenes inestables

Se añadió un chequeo previo de la respuesta del bot y una ruta de reintento si X devolvía error.

4. JSON roto por comillas dobles en el texto

Se implementó un sanitizador automático que limpia el JSON sin romper emojis ni formato.

Resultado final

El agente publica de manera autónoma una noticia diaria de vino con: texto en tono Mi Mundo del Vino + imagen generada + registro analítico en Notion.
