🤖 Proyecto MMDV — AI Social Media Agent

Agente social autónomo que detecta noticias de vino, genera texto con mi estilo, crea una imagen personalizada y publica en X (Twitter) sin intervención manual.

Resumen del proyecto

Este proyecto desarrolla un agente social autónomo capaz de:

  • Leer noticias en tiempo real desde fuentes RSS especializadas en vino.
  • Seleccionar automáticamente una noticia mediante un sistema aleatorio controlado.
  • Generar un tweet con mi estilo (“Mi Mundo del Vino”).
  • Crear una imagen coherente con el contexto de la noticia.
  • Publicar automáticamente en X usando un bot propio desplegado en Render.
  • Registrar cada post en una base de datos de Notion para análisis posterior.

La integración está construida con Make (antes Integromat), OpenAI GPT-5.1 para texto, DALL-E 3.5 para imágenes, y un backend propio en Python/FastAPI para controlar la publicación en X mediante OAuth1.

Arquitectura del agente

A nivel funcional, el flujo completo del agente es:

  • RSS Watcher: escucha nuevas noticias (Wein.plus, Decanter, OIV…).
  • Selector aleatorio: módulo Switch que rota entre 3 feeds.
  • GPT – Redacción: genera el texto del tweet con mi estilo.
  • DALL-E – Imagen: crea una imagen con contexto actualizado.
  • HTTP → Bot X: envía texto + imagen al backend propio.
  • Notion: registra datos del post, URLs, métricas iniciales…

Workflow en Make

El escenario en Make orquesta todas las piezas: desde el disparador RSS hasta la publicación final en X y el registro en Notion.

Bot de publicación en X

La pieza clave del sistema es un bot propio desplegado en Render que recibe peticiones desde Make y publica en X mediante OAuth 1.0a.

¿Por qué un bot propio y no el módulo nativo de X en Make?

  • Las credenciales de X (API key, secret, access token…) se gestionan en un solo backend, nunca se exponen en Make.
  • Necesitábamos enviar texto + imagen en un único request firmado (multipart), algo que el conector estándar limita bastante.
  • El bot puede aplicar lógica adicional: validaciones, saneo de payload, reintentos y manejo fino de errores de la API de X.

El bot expone un endpoint /tweet-with-image que recibe:

  • text: tweet final generado por GPT y ya saneado.
  • image_base64: imagen creada por DALL·E 3.5.

El backend valida el payload, gestiona errores de la API de X y devuelve el ID del tweet para que Make lo registre en Notion.

Problemas técnicos superados

1. Límite de 4000 caracteres en prompts

Se solucionó dividiendo el prompt en instrucciones fijas + contenido dinámico limpio, evitando desbordar el límite de tokens y manteniendo contexto suficiente.

2. Autenticación segura con X (OAuth 1.0a)

Gestionar las credenciales de X directamente desde Make no era viable a nivel de seguridad ni de control. La solución fue crear un bot propio que firma las peticiones con OAuth 1.0a y centraliza todas las claves en el backend, dejando a Make como orquestador sin exponer secretos.

3. Penalización de X por imágenes inestables

Se añadió verificación previa de contenido y un fallback automático en caso de error del servidor de X o de problemas en el upload de la imagen, reduciendo el riesgo de bloqueos temporales.

4. JSON roto por comillas

El payload hacia el bot pasó por un sanitizador automático que limpia el texto sin romper emojis, evitando errores de parseo en el backend al enviar comillas y caracteres especiales.

Resultado final

El agente publica de manera autónoma una noticia diaria de vino con: texto personalizado, imagen generada y registro automático en Notion. Todo ello manteniendo el estilo característico de Mi Mundo del Vino: elegante, irónico, técnico y moderno.
